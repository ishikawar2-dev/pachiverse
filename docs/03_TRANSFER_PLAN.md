本書は「Pachiverse を UNI へ引き渡す際の価格をどう説明するか」と「評価額を上げるために 10 月末までに何をやるか」をまとめたもの。
価格の元資料はリポジトリ外の `Pachiverse_開発工数表_v1.1_2026-09-07.md`（ルート直下、Git 管理外）。

## 1. 前提（オーナー確定 2026-09-15）

| 項目 | 内容 | 影響 |
|---|---|---|
| IP 帰属 | **すべて石川**。コード・命名・ロゴ・アート・文書を含む | 譲渡対価に相殺・按分の要素がない。DD では帰属の証跡（コミット履歴、制作記録、対価なしの証跡）を求められる |
| 既払い対価 | **なし**。UNI から開発費等を受け取っていない | 「残余対価」ではなく全額の譲渡対価として交渉する |
| 引き渡し範囲 | pachiverse.com（プロジェクトページ）・members.pachiverse.com・contracts・signer・pvm-art。**メタバース（pachiverse-world）の含否は未決** | 工数表 v1.1 はメタバースを対象外としている。含めるなら別途評価 |
| 法務意見書 | 今回スコープ外 | 資金決済法・課税・KYC・景表法は未解決のまま提示する。価格の上限を抑える要因として残る |
| 期限 | **10/31 までに監査以外を完了、11 月から第三者監査** | 監査は 1〜2 ヶ月。レポートは 12 月〜2027 年 1 月が現実的 |

石川と UNI の関係（オーナー確定 2026-09-15）: **石川は UNI の役員ではないが 100% 株主**。現代表は高橋氏。

この関係から導かれる整理:
- 会社法上の利益相反取引（取締役と会社の取引）には**該当しない**。UNI 側の手続きは現代表の承認（取締役会設置会社なら取締役会決議）で足りる。必要なら現代表から承認を取る手続きを実行する。
- 一方で、100% 株主と会社の取引は**税務上「時価」の客観性が問われる**。個人→法人の譲渡が時価の 1/2 未満なら所得税法上のみなし譲渡（時価で譲渡したものとみなされる）、時価を大きく超えれば法人側で寄附金等の認定リスクがある。**したがって本計画の評価資料（工数表 v1.2・第三者監査・事業実績）は、UNI を説得するためではなく、税務署と将来の第三者（投資家・次の買い手・債権者）に対して価格の合理性を示すためのもの**と位置づける。税理士への事前確認をオーナーが手配する。
- 会員の本名・連絡先を含む DB を UNI へ移す場合、事業承継に伴う個人データの提供として整理し、会員への通知文案を用意する。

## 2. 価格の現在地

### 2.1 工数表 v1.1 の 3 段階（原文の値）

| 区分 | 金額 | 根拠 |
|---|---|---|
| ① 再調達原価（外注相当） | 約 6,500〜9,000 万円（代表値 約 7,500 万円） | 63.5 人月 × 110〜135 万円/月 |
| ② 譲渡時の実勢目安 | 約 3,500〜5,500 万円 | ①の 5〜7 割から改修費 500〜800 万円と実績未整備を織り込む |
| ③ 減点要因解消後の上限 | 約 5,500〜7,000 万円 | 減点要因を解消し、安定稼働実績と事業実績の数値を添えた場合（7〜8 割） |

### 2.2 v1.2 で直すべき点（2026-09-15 の評価で判明）

- **数式が緩い**。7,500 万円 × 5〜7 割 − 改修費 500〜800 万円 ＝ 2,950〜4,750 万円で、②の上限 5,500 万円に届かない。③も 7〜8 割なら 5,250〜6,000 万円で、7,000 万円は約 93% 相当。買い手に検算されると信頼を落とすので、掛け率か丸め方のどちらかに揃える。
- 「KMS・マルチシグ・監査を解消したら 4,500〜6,000 万円」という中間推定は**撤回**。②③と大部分が重なり意思決定に使えない。3 点を解消した状態は「②の上端（5,000 万円前後）を説明しやすくなる」と表現する。
- 売り手＝開発者本人の自己評価であることを明記する。買い手は人月・単価を値切る前提で、WordPress＋自作プラグイン部分は再調達が安い。
- IP 帰属（石川）と既払いなしを前提条件として本文に書く。

### 2.3 評価を下げ得る要因

- **事業実績を出すと下がるリスク**。収益が小さければ収益還元法が原価法を下回り、買い手は低い方を採る。実績資料を UNI に出す前に**内部で速報値を確認**する（計画 B-1）。
- 法務未解決は減点ではなく go/no-go。資金決済法の結論次第で価値がゼロにもなり得る。今回はスコープ外だが、UNI 側が DD で必ず聞く。
- 安定稼働実績は工数表上 3 ヶ月分が目安。9/9 Reveal 起点では 10/31 時点で 7 週分しかない。目標は「記録を開始し空白なく積む」に置き換える。
