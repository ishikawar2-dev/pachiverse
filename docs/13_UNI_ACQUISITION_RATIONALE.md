## 1. 決裁を求める事項

当社は、当社の会員向けサービスの運用に現に使用している Pachiverse 一式の著作権その他の知的財産権を、石川から取得する。取得価額は第三者の無形資産評価書に依り、決済は石川への役員貸付金との相殺による（§6）。

## 3. 取得の必要性（事業継続に不可欠）

### 3.1 当社事業の基盤として本番稼働している

- 当社・VB の会員（完全紹介制）が保有する商品換価権 NFT・パック・PV Coin 等の管理は、本システムを唯一の運用基盤としている。業務状態の正本は会員サイト、鍵を持つのは Signer のみという構成で、代替経路はない（00_OVERVIEW「システム構成概要」）。
- 2026-09-09 に Reveal（パック開封）を本番公開し、初週に burn 5 バッチ 64 枚が confirmed、日次整合性検証は記録のある 9/9〜9/13 すべて成功。インシデントは S1（全停止・資産流出等）0 件、S2 は 2 件（burn バッチの送信遅延と付与の誤りで、いずれも会員の権利の正本に影響なく是正済み）（members `ops/OPERATIONS_LOG.md` §3・§4）。

### 3.2 利用規模（基準時刻 2026-09-13 15:00、06 §1〜§2）

| 段 | 値 | 定義 |
|---|---:|---|
| 登録 | 4,634 | 本番 DB のユーザー全行（会員 4,631・運営 3） |
| 利用開始 | 1,721 | 初回ログインを完了しマイページを開いた会員（登録比 37.1%） |
| 90 日活動 | 711 | 最終ログインが基準時刻から 90 日以内（登録比 15.3%） |
| 参考: 商品換価権 NFT の保有者 | 1,235 | パック・持分・パチプロ・島・mini のいずれかを保有 |

本表は稼働の証拠としてのみ用いる。会員は当社の既存顧客であり、会員数・保有者数を顧客基盤の資産価値として取得価額に算入しない（03 §2.4.1）。

### 3.3 本システムが使えなくなった場合に止まる業務（07 §4）

| 業務 | 担うシステム | 止まった場合 |
|---|---|---|
| 会員の保有表示・マイページ・本人確認 | 会員サイト | 会員が保有・残高を確認できない |
| PV Coin 台帳・監査ログ・日次の資産レコンサイル | 会員サイト | 記帳と不整合の検知が止まる |
| パック開封（Reveal）と Machine NFT の割当 | 会員サイト・コントラクト | 開封できない |
| 日次 burn（開封済みパックの焼却） | Signer・コントラクト | TX が出ず、オンチェーンと正本の不整合が続く |
| 出庫（会員ウォレットへの NFT 送信） | 会員サイト・Signer | 送付できない（現在は機能フラグ OFF） |
| 会員サポート（受信箱・AI 分類・FAQ）・サポーターズ倶楽部月次メール | 会員サイト | 会員対応と定期連絡が止まる |
| 対外説明（コントラクト一覧・FAQ・Collection Explorer） | 公開サイト | 公開情報の窓口がなくなる |
| NFT 画像・metadata の保全 | pvm-art | IPFS のピン消失時に復旧できない（既存 14 種で前例あり、05 G） |

会員の権利の記録は当社 DB に残るため直ちに失われはしないが（07 §4）、上記の運用はすべて停止する。メタバースの事業上の位置づけは [要確認: 当社としての利用計画・時期]。

## 4. 代替案の比較

| 案 | 内容 | 費用・期間 | 主なリスク | 評価 |
|---|---|---|---|---|
| (a) 外注で同等システムを新規構築 | 2〜3 社の外注見積（NDA のうえ実物ベースで見積）で再調達 | 外注見積の金額・期間 [要確認: 見積受領後に記入]（03 §2.4、05 §5-7） | コントラクトは変更不可（07 §2）で、既存 NFT・会員台帳・Signer 接続仕様への完全互換が必要。NFT アート 500 体は著作物であり再制作では同一物にならない。移行期間中の運用停止・データ移行の誤りが会員資産に直結する | 費用・期間・移行リスクのいずれも (c) に劣る |
| (b) 取得せず、個人所有のまま利用を続ける | 石川個人の IP を当社が使用する現状の継続 | 取得費用なし。利用許諾契約はなく、当社は無償で使用している（オーナー確認 2026-09-24） | 事業基盤の権利が個人に残り、使用継続が個人の事情（意思・相続等）に左右される。外部アカウントの多くが個人名義（05 H、07 §2）。Safe 移行後は当社が ADMIN 鍵を持つ一方でコードの権利は個人に残り、権限と権利が一致しない。保守満了時の個人権限の剥奪（09 §6）ができない | 継続性・監査対応の両面で不可 |
| (c) 本件取得 | IP を当社へ移転し、12 ヶ月の無償保守で運用を移す | 評価書の時価（§5） | 取得後の減損（§8）、法務論点（§9） | **採用** |

(c) が合理的である理由: 当社の既存会員向けサービスを止めずに、権利と運用権限を当社に揃えられる唯一の案であり、価格は再調達原価（(a) の費用）から陳腐化を控除した水準に第三者評価で限定される。

## 8. 会計処理と留意点

- 取得価額＝支払額としてソフトウェア（5 年償却）に計上する。代表取締役は了承済み。**顧問税理士の見解は未取得**（U-6、ヒアリング原本 (2) B-3）。
- NFT アート・公開サイト・メタバースを同一区分（ソフトウェア）で計上するか [要確認: 資産区分と耐用年数]。
- 2025/11 以降、本基盤上の売上はない（05 E）。収益が生じなければ翌期以降に減損の論点が出る。減損判定時は、本書 §3（事業継続に不可欠・現に使用中）と §4（代替費用）を取得時の判断根拠として示す（03 §5）。
